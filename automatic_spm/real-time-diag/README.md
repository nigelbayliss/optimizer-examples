# Identifying Cases Where Real-time SPM Has Resolved a Performance Issue

This demonstration is intended for Oracle Autonomous Database (19c and above)

- list.sql lists real-time SPM information for all SQL plan baselines
- regressions_prevented.sql lists the total number of SQL performance regressions prevented 
- regressions_prevented_since_upgrade.sql lists the number of SQL performance regressions prevented by real-time SPM since the last upgrade 

DISCLAIMER:
- These scripts are provided for educational purposes only.
- They are NOT supported by Oracle World Wide Technical Support.
- The scripts have been tested and they appear to work as intended.
- You should always run scripts on a test instance.
